## Design Features

### ✅ **Visual Elements**
- **Large emoji icons** (🏘️ for townhomes, 🏨 for hotels)
- **Bold project names** in 2.5rem Montserrat font
- **Key metrics** prominently displayed (units, financing, location)
- **Project status** and website URLs
- **Ocean blue gradient** background matching brand colors

### ✅ **Typography**
- **Project Name:** 2.5rem, weight 800, white with text shadow
- **Details:** 1.3rem, weight 500, 95% opacity
- **Status Line:** 1rem, italic, 80% opacity
- **All text:** White for maximum contrast on gradient

### ✅ **Professional Styling**
- **Gradient:** Charcoal (#2c3e50) → Mid-gray (#34495e) → Ocean Blue (#0077be)
- **Height:** 450px (generous spacing)
- **Rounded corners:** Top only (10px radius)
- **Inner shadow:** Subtle depth effect
- **Icon shadow:** Drop shadow for depth

2. Set sharing to "Anyone with link"
3. Use direct link format
